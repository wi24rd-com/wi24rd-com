**Wi24rd** is an independent open cybersecurity initiative from Denmark: free, open-source tools and plain-language guidance that make security easier to understand and act on.

No tool, purchase or title makes anyone fully secure. Every project here says what it does, and what it does not.

Built by Jan Tingsvad, who has been writing code since 1995.

## Projects

## How it is built

Open code. Clear evidence. Human responsibility.

- All code is public, so you can read it before you trust it.
- Every change leaves a trail: public commits, test output and screenshots.
- AI agents do the work, an independent check verifies it, and nothing ships without human approval.

The method is called **[ASEWAVE](https://asewave.org)**: Augmented Solo Engineering With Adversarial Verification + Evidence. Developed by Wi24rd while building XDRagon Monitor, and documented openly on its own site.
